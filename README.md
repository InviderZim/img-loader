# Сервер зображень

Це навчальний проект на Python.
Суть проекту — можна завантажити зображення, зберегти його та отримати посилання на нього.

## Що використовується

* Python
* Nginx
* Docker
* Docker Compose

## Що вміє проект

* показує головну сторінку;
* дозволяє завантажувати зображення;
* підтримує `.jpg`, `.png`, `.gif`;
* максимальний розмір файлу — 5 МБ;
* для кожного файлу створюється унікальне ім'я;
* є сторінка з усіма завантаженими зображеннями;
* зображення роздає Nginx;
* дії записуються в `app.log`.

## Структура проекту

```text
img-loader/
├── app.py
├── requirements.txt
├── Dockerfile
├── compose.yaml
├── nginx.conf
├── images/
├── logs/
└── static/
    ├── index.html
    ├── upload.html
    └── images.html
```

## Як запустити

Потрібен встановлений Docker.

У папці проекту виконати:

```bash
docker compose up --build
```

Після запуску сайт доступний за адресою:

```text
http://localhost:8080/
```

Сторінка завантаження:

```text
http://localhost:8080/upload
```

Галерея:

```text
http://localhost:8080/images/
```

Python-сервер також доступний напряму:

```text
http://localhost:8000/
```

## Як зупинити

```bash
docker compose down
```

Зображення та логи зберігаються в Docker volumes, тому після перезапуску вони не видаляються.
